# CS101 Project: Airline Ticket Reservation Website

This repository contains a simple airline booking website with the following pages:

- `index.html` — home page
- `Book A Flight.html` — flight reservation form
- `Special Offers.html` — promotional offers page
- `Contact Us.html` — contact form and company info
- `About AIRLINE.html` — company and team information
- `Log in.html` — login page

## Notes

The pages reference local image assets such as `plane.jpeg`, `european city.jpeg`, `tropical city.jpg`, and `new york.jpg`. Add those files to the repository root if you want the visuals to render exactly as designed.
